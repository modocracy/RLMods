# 부스터 선택 연결 조사 — 2026-10-19

현재 상태: **미구현**. 사용자가 정상 동작을 확인한 0.1.5의 스트라타젬
랜덤 선택은 유지했다. 이 조사로 새 버전이나 설치용 패치를 만들지 않았다.
게임 실행, 프로세스 덤프, 실행 검증, 테스트, 자동 설치는 하지 않았다.

## 확인한 근거

- [HD2Runtime의 UI 분석](https://github.com/SkyeShade/HD2Runtime/blob/34fba0887b196130df4142933fbe1b6ff6be5020/scripts/research_runtime_stratagem_ui.py):
  헬포드 화면의 패널 포커스 0–3은 스트라타젬, 4는 화면 하위 상태 5에
  대응한다. 하위 상태는 매 프레임 포커스에서 계산되며 선택창이 열렸다는
  뜻이 아니다. 선택창 열림 바이트는 별도로 검사해야 한다.
  공개 분석은 스트라타젬 적용 경로를 다루며 부스터 분기의 전체 계약을
  제공하지 않는다. 해당 연구의 game.dll SHA256은 이 프로젝트의 설치
  버전 메타데이터와 일치한다.
- [FlexibleLoadouts의 선택 목록 함수](https://github.com/Alomare/FlexibleLoadouts/blob/39871d310d3942f718648280fe5c60cc4d2beaac/flexible_stratagems.lua):
  목록의 선택 ID를 설정하는 함수와 선택 가능 표시를 읽는 구조가 있다.
  목록 ID 설정만으로 장착·저장 완료가 보장되지는 않는다. 스트라타젬용
  목록 표시를 부스터의 소유권 증명으로 대체하지 않았다.
- [HD2-Transmog의 명령어 서명](https://github.com/tyrypyrking/HD2-Transmog/blob/f469851dcb5bf241a08be5329728ca649710896c/src/compat_spec.lua):
  `extra_booster_host`라는 744바이트 서명이 있다. 공개된 바이트만
  Capstone 5.0.7로 정적으로 해석했다. 함수 시작 상대 위치 +0xFD의
  저장은 관리자 +0xA8C + index*64에 이뤄진다. +0x229에서는 인수와
  0x15를 비교하며, 이 특수 분기는 화면의 +0x2808을 확인하고
  +0x27D8의 인덱스 배열을 사용한다. 일반 분기에는 상태 기록과 메시지
  호출이 있다. 이 사실만으로 호출 인수, 소유권 검사, 팀 부스터 중복
  검사, 헬포드 페이로드 갱신과 저장이 모두 입증되는 것은 아니다.
  동일 리비전의 공개 텍스트 소스에서는 이 서명의 사용처를 찾지 못했다.
  원본 구현은 복사하지 않았고 이 함수를 호출하는 코드도 추가하지 않았다.
- [HD2Runtime 부스터 분석](https://github.com/SkyeShade/HD2Runtime/blob/34fba0887b196130df4142933fbe1b6ff6be5020/scripts/research_booster_native.py)은
  효과 테이블과 활성 상태를 다룬다. 정상 로드아웃 선택 API와는 구분했다.
- [Personal Booster](https://github.com/modocracy/personal-booster)는 실행 중
  분대 부스터 슬롯을 바꾸는 방식이다. 이번 요청의 정상 헬포드 부스터
  선택 구현에 사용하지 않았다.

## 남은 연결 지점

1. 부스터 후보의 offer ID, item ID, 부스터 enum 사이의 대응과 실제 보유 판정.
2. 헬포드 부스터 목록의 선택 가능 표시가 임무·팀 제한을 적용하는 정확한 경로.
3. 일반 선택 핸들러의 부스터 분기, 호출 계약, 로컬 플레이어 식별.
4. 선택 후 프로필 저장·팀 전달·화면 갱신 및 결과를 확인할 필드.

설치된 원본 PE는 앞서 기록한 대로 패킹되어 있어, 이번에 필요한 함수의
전체 명령어를 디스크 파일에서 확인하지 못했다. 실제 게임 파일을 읽었다는
사실을 이 누락된 함수들의 확인으로 간주하지 않는다. 임의 주소나 구조를
채워 넣거나, 스트라타젬의 소유권 규칙을 부스터에 그대로 적용하지 않았다.

[DiverKit](https://www.nexusmods.com/helldivers2/mods/16493)과
[Dive Ready](https://www.nexusmods.com/helldivers2/mods/17214)는 관련 기능을
안내하는 다른 제작자의 모드다. 기능 안내는 이 프로젝트의 구현 근거가
아니다. 사용자는 해당 파일을 가지고 있지 않다고 답했다. 두 모드의
설치·의존성 추가를 요구하지 않으며, 그 구현을 확보하거나 분석했다고
주장하지 않는다.

## 결과물과 변경 범위

이번 조사 결과물은 이 문서뿐이다. 분석 도구와 공개 소스 임시 사본은
기존 `.git/info/exclude`의 `/.work/` 아래에만 두었다. 제품 Lua 코드,
버전, 기존 ZIP은 변경하지 않았다. 전체 기존 소스가 미추적 상태여서
이번 조사만의 깨끗한 코드 변경·검증 단위도 없으며 커밋하지 않았다.
