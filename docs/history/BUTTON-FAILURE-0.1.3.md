# 클릭 후 선택 실패: 0.1.3 진단 패치

사용자가 0.1.2로 플레이한 뒤 허용한 `RLMmods.log`를 읽었습니다.
클릭은 처리됐지만 `Fewer than four compatible, available stratagems`와
`Stratagem grid focus unavailable`로 거부됐습니다. 성공 기록은 없습니다.
이는 사용자 실행 기록이며 개발자의 게임 실행·테스트 결과가 아닙니다.

## 변경

소유권 관찰기의 `available=false`와 실패 사유를 카탈로그 호출자가 무시하여
조회 불가와 실제 후보 부족을 같은 오류로 표시했습니다. 이제 원래 사유를
로그에 남기고 중단합니다. 후보 필터 단계별 개수, 소유권 거부 이유별 개수와
요청 단계(snapshot/catalog/plan/apply)를 기록합니다. 포커스 거부 시 실제 값도
기록합니다. 원시 메모리·플레이어 식별자는 기록하지 않습니다.

화면 오류를 최대 세 줄로 표시하고 새 세션에서도 이전 로그를 보존합니다.
소유권·선택 가능 여부·중복·차량 제한과 적용 함수는 완화하거나 대체하지 않았습니다.
시작 경로는 기존 `boot.lua` 방식 그대로이며 Bingus를 요구하지 않습니다.

## 남은 차단 원인

0.1.2 로그에는 원래 소유권 오류와 단계별 후보 수가 없습니다. 소유권 서명 불일치,
관찰 실패, 목록/아이템 매핑 불일치, 실제 후보 부족 중 무엇인지 확정할 수 없습니다.
범위 밖 포커스 값을 안전하게 복원할 근거도 없어 임의로 허용하지 않았습니다.
**0.1.3은 진단·오류 처리 수정이며 랜덤 선택 작동을 확인한 수정본이 아닙니다.**

## 설치 및 사용자 확인

1. 게임을 닫고 이전 RLMmods를 모두 비활성화합니다. Bingus는 유지할 수 있습니다.
2. `dist/RLMmods-0.1.3-diagnostic-private-untested.zip`을 모드 매니저에 가져와 배포합니다.
3. 헬포드 화면에서 준비를 해제하고 개별 선택 창을 닫은 뒤 버튼을 한 번 누릅니다.
4. 포커스 안내가 뜨면 스트라타젬 슬롯 하나를 눌러 목록을 열었다가 닫고 다시 누릅니다.
5. `%LOCALAPPDATA%\RLMmods\RLMmods.log`의 `0.1.3-diagnostic` 세션으로 원인을 좁힙니다.

버튼 위에 `0.1.3 | DIAGNOSTIC`을 표시합니다. 다른 `boot.lua` 교체 모드와 충돌합니다.
제거는 같은 모드 매니저에서 비활성화 후 Purge/Deploy합니다. 자동 설치와 원본 덮어쓰기는 하지 않습니다.

소스 ZIP은 새로 만들지 않습니다. 설치 패치는 원본 boot 바이트코드를 포함하므로 공개하지 않습니다.
전체 장비 랜덤화와 정식 메뉴 위젯 통합은 여전히 미완성입니다.
컴파일·패키징만 수행하며 게임 실행·테스트·모드 매니저 설치·실행 검증은 수행하지 않습니다.
