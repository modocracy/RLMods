# 0.5.0: 키보드·패드로 버튼 선택

설치 파일: `dist/RLMmods-0.5.0-private-untested.zip`. 이전 RLMmods는 모두 끄고 교체하세요.
컴파일·패키징만 했고, 게임 안 동작은 아직 확인하지 않았습니다.

## 조작

플레이어 카드의 기존 포커스 순서에 이어 붙였습니다.

```text
[저장]         ↑↓ 로 이동, 선택키로 실행
[불러오기]
[랜덤]
  ↑ (막대에서)    ↓ (랜덤에서) / ← → / 뒤로 → 막대로 복귀
[R 장비] 막대
[임무 스트라타젬 줄]
[스트라타젬·부스터 줄]
```

- 임무 스트라타젬 줄에서 ↑를 누르면 게임이 "R 장비" 막대로 포커스를 옮깁니다(기존 동작).
  막대에서 ↑를 한 번 더 누르면 랜덤 버튼으로 포커스가 옵니다. 게임은 이때 원래 아무것도 하지 않습니다.
- 포커스가 있는 버튼은 마우스 호버와 같은 노란 상태로 표시되고 툴팁이 나옵니다.
- 마우스 클릭도 그대로 됩니다.

## 동작 방식과 근거

- 메뉴 입력: 입력 객체(전역 `0x347CF18`)의 `+0x328 + 동작번호×32` 바이트.
  ↑ 1·5, ↓ 2·6, → 3·7, ← 4·8, 뒤로 9, 선택 10 (방향 판정 `0x178E020`, 5~8은 길게 누름 반복).
- 막대 포커스: 패널(`screen+0x53A78`)의 `+0x1B81E`가 0이면 막대(`+0x1B820`)에 포커스가 있는 상태
  (`0x189BF51`에서 칸 → 막대, `0x189BE27`에서 막대 → 칸). 막대 강조는 `0x1892200`.
- 버튼에 포커스가 있는 동안에는 게임이 입력을 읽기 직전에 메뉴 동작 1~10의 입력 값을 지웁니다.
  그래서 같은 키에 게임 카드가 반응하지 않습니다. R·B 같은 단축키는 건드리지 않습니다.
- 버튼에 포커스가 오면 막대 강조를 끄고, 막대로 돌아갈 때 다시 켭니다.
- 다른 팀원 카드를 보고 있거나 선택 목록이 열려 있으면 버튼 포커스를 해제합니다.
- 의존하는 코드 6곳의 바이트가 다르면 이 기능만 꺼지고, 마우스 버튼은 그대로 동작합니다.

## 확인하지 않은 것

게임 안 포커스 이동, 패드 조작, 막대 강조 표시, 길게 누름, 장비 보기(R) 상태에서의 이동.
로그에 `Navigation:` 줄로 포커스 진입·복귀·선택이 남습니다.

## 0.5.1~0.5.2

- 0.5.0 로그에서 버튼 포커스 진입·복귀는 4번 기록됐지만, 선택키 실행 기록은 없었습니다.
  0.5.1부터 버튼 포커스 중 눌린 메뉴 동작 번호를 `Navigation: actions ...`로 기록하고,
  떠날 때 쓴 키(left/right/back)도 기록합니다.
- 0.5.2: 큰 툴팁 패널을 없애고, 마우스를 올리거나 포커스가 있는 버튼 바로 아래에
  `저장`·`불러오기`·`랜덤` 이름표만 작게 표시합니다. 실행 결과와 거부 이유는 로그에만 남습니다.

## 0.5.3

사용자 화면: 랜덤 실행 뒤 커서가 첫 스트라타젬 칸으로 옮겨져 연속 실행이 안 됐습니다.
목록을 읽으려고 포커스를 잠시 첫 칸으로 옮긴 뒤, 원래 포커스가 비어 있던 경우(-1)에도
첫 칸에 남겨 두던 동작 때문이었습니다. 스트라타젬·부스터 모두 원래 포커스를 그대로 되돌리고
(빈 상태와 임무 스트라타젬 줄 포함), 버튼 포커스 중에는 실행 뒤 다시 켜진 막대 강조를 끕니다.

## 0.5.4

- 0.5.3 로그: 버튼 포커스에서 선택키(메뉴 동작 10)로 랜덤 70회, 불러오기 7회, 저장 1회 실행. 오류 0.
  진단용 동작 번호 기록은 다시 끕니다.
- 랜덤 부스터에서 0번(미선택)을 뺍니다. 팀 중복 검사 `0x875110`이 0번만 항상 허용하는 것이
  "부스터 없음"이기 때문입니다. 불러오기는 저장된 상태가 미선택이면 미선택으로 복원합니다.

## 0.5.5 표시 시점과 등장 효과

- 헬포드 화면은 탭 2개(브리핑·드랍 위치 = 0, 장비구성 = 1)이고, 현재 탭은 화면 객체 `+0x8`입니다
  (탭 전환 `0x1470D90`이 기록, 화면 갱신 `0x146D55A`가 읽음). 출격이 시작되면 `+0x2808`이 켜집니다.
- 버튼은 장비구성 탭이면서 출격 전일 때만 표시합니다. 드랍 위치를 고르는 동안에는 보이지 않습니다.
- 장비구성 탭이 열리면 버튼이 아래에서 180px(1080p 기준) 올라오며 0.35초 동안 서서히 나타납니다.
  다 올라올 때까지는 클릭·키 입력을 받지 않습니다.
- 해당 코드 4곳이 다르면 이전처럼 헬포드 화면 전체에서 표시합니다.
