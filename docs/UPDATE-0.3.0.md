# 0.3.0: 로드아웃 저장·불러오기

랜덤을 여러 번 눌러도 원래 쓰던 구성으로 바로 돌아가거나, 자기 구성을 바로 불러오기 위한 기능입니다.
컴파일·패키징만 했고, 게임 안 동작은 아직 확인하지 않았습니다.

설치 파일: `dist/RLMmods-0.3.0-private-untested.zip`. 이전 RLMmods는 모두 끄고 교체하세요.

## 버튼

| 버튼 | 동작 |
| --- | --- |
| 저장 (디스크) | 지금 장착한 스트라타젬 4개, 부스터, 헬멧·방어구·망토, 주무기·보조무기·수류탄을 저장 |
| 불러오기 (화살표) | 저장한 구성으로 복원. 저장 파일이 없으면 비활성 |
| 랜덤 (주사위) | 이전과 같음 |

저장 칸은 1개이며 저장할 때마다 덮어씁니다.
파일: `%LOCALAPPDATA%\RLMmods\loadout-1.txt` (줄마다 `항목=ID`).

## 불러오기 규칙

- 이미 같은 장비를 낀 칸은 건드리지 않습니다.
- 바꿔야 하는 칸은 랜덤과 같은 방식으로 게임 목록을 열고, 저장된 ID와 같은 행을 골라
  게임의 확정 처리와 같은 함수로 장착합니다.
- 지금 고를 수 없는 장비(임무 제한, 팀원이 쓰는 부스터, 미보유 등)는 그 칸만 건너뛰고
  나머지는 계속 불러옵니다. 결과와 건너뛴 칸은 버튼 설명과 로그에 남습니다.
- 스트라타젬은 4개를 한 번에 바꿉니다. 하나라도 지금 고를 수 없으면 스트라타젬은 그대로 둡니다.
  이미 로드아웃에 있는 스트라타젬은 자리만 바꿔도 허용합니다.
- 랜덤 전용 규칙(배낭 1개, 차량 1개)은 불러오기에 적용하지 않습니다. 게임 자체 규칙
  (메크·FRV·탱크 각 1개)은 그대로 지킵니다.

## 확인하지 않은 것

게임 실행, 저장·불러오기 버튼 동작, 출격 후 적용, 멀티플레이.

## 0.3.1~0.3.2 보완

- 0.3.1: 첫 저장 때 스트라타젬 4칸이 모두 비어 있어 스트라타젬이 저장되지 않았습니다.
  빈 칸은 이제 `0`으로 저장하고, 불러올 때 빈 칸으로 되돌립니다.
- 0.3.2: 사용자 보고로는 처음 불러올 때 수류탄이 다른 것으로 보이고, 다시 누르면 맞게 보였습니다.
  로그상 기록(블록 `+0xC0`)은 첫 번째에 이미 저장값이었습니다. 장비 화면의 6칸 표시 갱신 함수
  `0x18991A0`은 화면이 다른 기록에 연결될 때만 표시를 다시 읽습니다. 그래서 같은 화면에서 바꾼
  마지막 칸의 표시가 늦게 따라온 것으로 판단했습니다. 장비 변경 뒤에는 같은 함수가 하는 대로
  칸별 표시 함수 `0x18975D0`을 6칸 모두에 다시 부릅니다. 이미 같은 표시면 그 함수가 아무것도 하지 않습니다.
