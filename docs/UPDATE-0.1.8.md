# 0.1.8: 헬멧·방어구·망토·주무기·보조무기·수류탄 랜덤 선택

랜덤 버튼 한 번에 스트라타젬 4칸, 부스터, 장비 6칸을 차례로 고릅니다.
각 칸의 결과는 독립적입니다. 한 칸이 거부되어도 나머지는 진행됩니다.
컴파일·패키징만 했고, 게임 안 동작은 아직 확인하지 않았습니다.

설치 파일: `dist/RLMmods-0.1.8-private-untested.zip`. 이전 RLMmods는 모두 끄고 교체하세요.

## 근거 (0.1.6 진단판이 저장한 game.dll 코드 사본 해석)

| 위치 | 역할 |
| --- | --- |
| `0x189A2B0` | 패널 보기 모드 설정 (0: 스트라타젬, 1: 장비). 모드 값은 `screen+0x6F290` |
| `0x189C5FC` | 게임의 보기 전환 버튼 처리. 전환 함수 `0x189A650`이 위 함수를 호출 |
| `0x1898910` | 장비 칸 포커스 이동. 포커스 값은 `screen+0x6F284` |
| `0x146EA7B` | 목록 열기(모드 1): 포커스 0~2 → 종류 3, 3~5 → 종류 1 |
| `0x146F38C` | 포커스 → 하위 칸 번호 표 (`screen+0x281C`) |
| `0x146E1B3` | 목록 확정: 선택 offer → progression 표에서 item ID 조회 |
| `0x146E785` | 종류 3: 헬멧 `+0x124`/망토 `+0x128`/방어구 `+0x12C` 기록 후 동기화 함수 호출 |
| `0x146E7E7` | 종류 1: `0x1365EF0(0, 로드아웃 블록, 칸, 종류, item)` |

포커스와 칸 대응:

| 포커스 | 칸 | 확정 처리 |
| --- | --- | --- |
| 0 | 헬멧 | `+0x124`, `0x875CD0` |
| 1 | 방어구 | `+0x12C`, `0x8760B0` |
| 2 | 망토 | `+0x128`, `0x875EC0` |
| 3 | 주무기 | `0x1365EF0`, 칸 1, 종류 1 |
| 4 | 보조무기 | `0x1365EF0`, 칸 3, 종류 2 |
| 5 | 수류탄 | `0x1365EF0`, 칸 4, 종류 4 |

## 구현 방식

1. 패널을 장비 보기로 전환하고 각 칸에 포커스를 맞춘 뒤 게임의 목록 열기 함수를 부릅니다.
2. 목록이 선택 가능으로 표시한 행만 후보로 씁니다. 방어구 계열은 현재 장착품을 제외합니다.
3. 게임의 확정 처리와 같은 기록·함수·인자로 장착하고 목록을 닫습니다.
4. 끝나면 보기 모드와 두 포커스를 원래대로 돌립니다.

의존하는 코드 11곳의 바이트가 정확히 일치할 때만 활성화됩니다. 다르면 장비 기능만 꺼집니다.
각 목록의 행(offer:선택 가능:item)은 로그에 남습니다.

## 확인하지 않은 것

게임 실행, 장비 화면 전환이 화면에 보이는 방식, 무기 장착 결과 확인 필드, 출격 후 적용, 멀티플레이.
무기는 현재 장착품 위치를 아직 모르므로 게임 목록의 선택 가능 표시에만 의존합니다.

## 0.1.9 보완

사용자 0.1.8 로그: 장비 6칸은 18회 중 18회 성공. 장비 보기를 열어 둔 상태에서 누른 5회는
스트라타젬·부스터 목록이 열리지 않았습니다(목록 열기가 보기 모드로 종류를 고르기 때문).

- 랜덤 시작 시 장비 보기였다면 스트라타젬 보기로 바꿔 진행하고, 끝나면 장비 보기로 되돌립니다.
- 무기 3종은 장착 직후 로드아웃 블록에서 새 item ID가 정확히 한 곳에만 있으면 그 위치를 기억해,
  다음부터 현재 무기를 후보에서 뺍니다. 위치를 모르면 이전처럼 중복이 나올 수 있습니다.
- 장비 목록은 모든 행이 선택 가능으로 표시됐습니다. 미보유 장비가 목록에서 어떻게 표시되는지는
  모든 장비를 보유한 사용자 계정으로는 확인할 수 없었습니다.

## 0.2.0 스트라타젬 규칙

RLMmods 자체 규칙입니다(게임은 더 허용합니다). 랜덤 4칸 안에서:

- 배낭 칸을 쓰는 스트라타젬은 최대 1개: 배낭 13종과 배낭을 함께 메는 지원무기 9종
  (AC-8, B/MD C4, B/FLAM-80, FAF-14, GL-28, GR-8, M-1000, RL-77, StA-X3).
- 차량은 종류와 상관없이 최대 1개: 엑소수트 4종, FRV 3종, 탱크 2종. 이전에는 종류별로 1개씩이라
  엑소수트+FRV+탱크가 함께 나올 수 있었습니다.

ID와 분류는 HD2Runtime의 `domains/stratagem_authoring.lua`(family)와
`domains/support_weapon_catalog.lua`(backpackDependent)에서 가져온 사실 자료입니다.
목록은 `src/stratagem_rules.lua`에 있습니다. 이후 업데이트로 추가된 배낭은 목록에 넣어야 하며,
차량은 게임 내부 종류 비트로도 판별합니다. 로그의 `Catalog:` 줄에 후보 중 차량·배낭 개수가,
`Stratagem plan:` 줄에 고른 4개와 분류가 남습니다.

## 0.2.1~0.2.2 배낭 판별

0.2.0 사용자 스크린샷에서 배낭 2개가 함께 나왔습니다. ID `45875024`가 HD2Runtime 목록보다
새로운 배낭 스트라타젬이었습니다. 0.2.1에서 후보 91개의 StratagemInfo 행을 기록해 비교한 결과,
플래그(`+0x104`, 기존 차량 종류 비트와 같은 필드)의 `0x8` 비트가 알려진 배낭 22개에만
켜져 있고 나머지 69개에는 꺼져 있었습니다(신규 `45875024` 포함).
0.2.2부터 이 비트로 배낭을 판별하고 ID 목록은 예비로만 씁니다. 행 기록은 기본으로 끕니다.
