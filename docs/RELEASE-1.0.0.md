**RLMmods 1.0.0 — Randomize Loadouts**

헬다이버즈 2 출격 로드아웃을 버튼 한 번에 랜덤으로 짜 주는 모드입니다.

- **랜덤:** 스트라타젬 4칸·부스터·헬멧·방어구·망토·주무기·보조무기·수류탄을 한 번에 무작위로. 지금 고를 수 있는 장비만 사용.
- **규칙:** 배낭류·차량·지원무기 각 최대 1개. 부스터는 '미선택'·팀원 부스터 제외.
- **저장 / 불러오기 (보조):** 평소 구성을 저장해 두고 한 번에 되돌리기.
- 마우스·키보드·패드 지원("R 장비" 막대에서 ↑).

**설치:** 게임 종료 → HD2MM 또는 Arsenal에 `RLMmods-1.0.0.zip` 가져오기 → 활성화 → Deploy

**주의**

**RLMmods 1.0.0 — Randomize Loadouts**

Roll a random Helldivers 2 loadout in one click: four stratagems, booster, helmet, armor, cape, primary, secondary and grenade, picked only from what you can select right now. At most one backpack, one vehicle and one support weapon; the booster is never "none" or a squadmate's. Save / Load gets your usual kit back. Mouse, keyboard and controller (Up from the "R Equipment" bar).

**Install:** close the game, import `RLMmods-1.0.0.zip` into HD2MM or Arsenal, enable, Deploy.

Game build 25480438 only; disable after game updates until a new release. Not compatible with other `boot.lua` replacements (Bingus is fine). No unlocks, no anti-cheat bypass. Use at your own risk.
