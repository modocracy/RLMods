Text for the GitHub release and the mod page. The HD2Runtime credit line is required
by its license wherever users see the mod.

## GitHub release / mod page (English)

**RLMmods 1.0.0 — Save, Load and Randomize buttons for the Hellpod loadout**

Adds three buttons to your player card on the Hellpod loadout screen:

- **Save** your current stratagems, booster, helmet, armor, cape, primary, secondary and grenade.
- **Load** them back in one click; anything not selectable right now is skipped.
- **Randomize** everything from what the game lets you pick. At most one backpack, one vehicle and one support weapon among the stratagems; the booster is never "none" or a squadmate's.

Works with mouse, keyboard and controller (Up from the "R Equipment" bar).

**Install:** close the game, import `RLMmods-1.0.0.zip` into HD2MM or Arsenal, enable, Deploy.

**Requirements and limits**

- Game build 25480438 only. On other builds it does nothing; disable it after game updates until a new release.
- Replaces `boot.lua`: not compatible with other `boot.lua` replacements. Bingus Shared Loader is fine.
- No data is sent anywhere; nothing bypasses anti-cheat or unlocks content. Use at your own risk.

## 모드 페이지 (한국어)

**RLMmods 1.0.0 — 헬포드 로드아웃 저장·불러오기·랜덤 버튼**

헬포드 로드아웃 화면의 내 카드에 버튼 3개를 추가합니다.

- **저장:** 지금 스트라타젬·부스터·헬멧·방어구·망토·주무기·보조무기·수류탄을 저장
- **불러오기:** 한 번에 되돌리기. 지금 고를 수 없는 장비는 건너뜀
- **랜덤:** 고를 수 있는 장비 중에서 전부 무작위. 스트라타젬은 배낭·차량·지원무기 각 최대 1개, 부스터는 미선택·팀원 부스터 제외

마우스·키보드·패드 모두 지원("R 장비" 막대에서 ↑).

**설치:** 게임 종료 → HD2MM 또는 Arsenal에 `RLMmods-1.0.0.zip` 가져오기 → 활성화 → Deploy

**요구 사항과 제한**

- 게임 빌드 25480438 전용. 다른 빌드에서는 동작하지 않으며, 게임 업데이트 후에는 새 버전이 나올 때까지 꺼 두세요.
- `boot.lua`를 교체하므로 같은 파일을 바꾸는 다른 모드와 함께 쓸 수 없습니다. Bingus Shared Loader는 괜찮습니다.
- 데이터를 외부로 보내지 않고, 안티치트 우회나 해금을 하지 않습니다. 사용 책임은 사용자에게 있습니다.
